# PockAI Subtitles (browser extension)

Sends the subtitles of the video you're watching to the Touch Bar via the PockAI app.
Works in Chrome, Edge, Brave, Arc, Opera, Vivaldi (any Chromium browser).

Install (one time):
1. PockAI menu bar icon → **Subtitles** → **Install Browser Extension…** (opens this folder).
2. In the browser open `chrome://extensions`, turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick this folder.
4. Play a video with subtitles on. They appear in the PockAI **Subtitles** widget.

Safari / other apps: turn on PockAI → Subtitles → **Read subtitles from screen**.
Local movies (IINA, VLC, QuickTime): put a `.srt` with the same name next to the movie, or use **Load Subtitle File…**.

Privacy: captions are only sent to `127.0.0.1` (this Mac). Nothing goes online.
